# TitleVision Assistant 0.2.0

This release adds the ↻ GitHub update button, stable history storage, previous-history import and safer reminder/page validation.

## Before operational use

- Import `data/history.sqlite3` from your previous app using **Import previous history**.
- Review the user guide and supervise one approved SLA update before batch use.
- Dates exclude weekends, not holidays. Confirm each delay reason against the order.

## Updates and trust

The app checks published stable GitHub Releases. Downloads are verified with SHA-256. Automatic installation requires valid matching publisher signatures; unsigned development artifacts require manual installation. No live order data or browser sessions are included.

See `CHANGELOG.md`, `VALIDATION.md` and the release assets for details. This is an independent project, not an official DataTrace product.
